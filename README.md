# Contact Management System – Python

## Project Overview

A simple command-line Contact Management System developed using Python. This project allows users to manage contact information through a menu-driven interface.

The project demonstrates fundamental Python programming concepts, including dictionaries, functions, loops, conditional statements, and basic error handling.

## Features

- **Add Contact:** Store a contact's name and phone number.
- **View Contacts:** Display all saved contacts.
- **Search Contact:** Find a contact by name.
- **Delete Contact:** Remove an existing contact.
- **Exit:** Safely terminate the application.

## Technologies Used

- Python 3
- Python Dictionaries
- Functions
- Loops and Conditional Statements
- Basic Exception Handling

## Learning Outcomes

Through this project, I gained practical experience in organizing Python code, managing data using dictionaries, implementing CRUD-like operations, and building interactive command-line applications.
